# 📊 Product Case Studies

Repositório com estudos de caso de produtos reais em que atuei como **Product Owner** e **QA**, cobrindo o ciclo completo: descoberta, documentação, priorização, desenvolvimento e validação.

Cada pasta representa um projeto e reúne a documentação de produto correspondente (contexto, requisitos, backlog, user stories, critérios de aceite, MVP, roadmap e métricas). Nomes de empresas e informações confidenciais foram omitidos ou generalizados.

## Projetos

| Projeto | Descrição | Minha Atuação |
|---|---|---|
| [01 - Sistema de Gestão de Estoque de Ativos de TI](./projeto-01-sistema-gestao-estoque) | Cadastro, movimentação, baixa e QR Code de ativos físicos e de software | PO, QA e Desenvolvedor |
| [02 - Plataforma de Crédito](./projeto-02-plataforma-credito) | Motor de análise que consolida múltiplas modalidades de crédito para o cliente | PO e QA |
| [03 - WhatsApp Omnichannel](./projeto-03-whatsapp-omnichannel) | Robô de autocontratação de produto de crédito via WhatsApp, sem atendente humano | PO e QA |
| [04 - Sales Agent IA](./projeto-04-sales-agent-ia) | Prospecção automatizada com análise de reputação, site e Instagram, e envio de proposta | Discovery, PO, Backlog |
| [05 - Sistema de Investimentos](./projeto-05-sistema-investimentos) | Consolidador de carteira com rebalanceamento automático baseado em tese de investimento | PO, QA e Desenvolvedor |

## Como ler este repositório

Cada projeto segue a mesma estrutura de documentação:

- **Contexto e Problema** — situação antes do produto existir
- **Objetivo e Usuários/Personas/Stakeholders**
- **Fluxos AS IS / TO BE**
- **Requisitos Funcionais e Não Funcionais**
- **Critérios de Aceite**
- **Priorização (MoSCoW)**
- **Backlog e User Stories (formato BDD)**
- **MVP e Roadmap**
- **Métricas (North Star, KPIs, OKRs)**
- **Lições Aprendidas**
